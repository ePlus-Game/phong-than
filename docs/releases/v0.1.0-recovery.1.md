# Phong Thần Recovery Toolkit v0.1.0-recovery.1

**Developer tools prerelease — NOT a playable Windows game build.**

The original 99,352 ZIP entries remain unchanged and SHA-256 auditable.

## Fixes

- Harden AccountServer gateway IPv4 parsing and bounded packet handling.
- Fail Modern builds if any source referenced by a VC6 DSP is missing.
- Fix legacy VC6 Debug artifact paths for Engine/LuaLibDll.
- Add a safe Windows build wrapper that copies source OUTSIDE the Git checkout,
  validates prerequisites, applies security fixes, then calls VC6/Modern build.
- Add static preflight and regression tests; package a reproducible toolkit ZIP
  with SHA-256 checksum.

## Verification and limitations

The release job tests the Python toolkit and builds the portable Lua/Common
subset with CMake/CTest on Ubuntu. No complete Windows GameClient/GameServer
compilation, login/map smoke test or executable compatibility has been proven.

This release does NOT ship compiled game executables or PAK assets in its ZIP.
GitHub automatically provides links to public source-code archives, which may
contain the previously published legacy content. Review redistribution rights,
accounts, logs, backups and other potentially sensitive data before sharing.
